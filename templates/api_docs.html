AVEC API Documentation

The AVEC API provides programmatic access to the variant assessment tool. You can retrieve the same detailed analysis available through the web interface via a simple POST request.

Endpoint

The base URL for the API endpoint is:

{{ url_for('api_assess', _external=True) }}

Request

The API accepts POST requests with a JSON body containing a single required key.

  • Key: query
  • Description: The variant to assess in a recognized HGVS-like format.
  • Examples: NM_015427.4:c.1054G>A, FKTN c.1312G>A

Example Usage (cURL)

curl -X POST "{{ url_for('api_assess', _external=True) }}"      -H "Content-Type: application/json"      -d '{"query": "NM_018026.4:c.607C>T"}'

Response

The API returns a JSON object containing the full assessment, structured identically to the data used by the web interface.

  • On success (HTTP 200), the response will contain `summary` and `assessments` objects.
  • On failure (e.g., invalid query or server error), it will return a JSON object with an `error` key and an appropriate HTTP status code (400, 404, 500).
